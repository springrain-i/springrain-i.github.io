## 目标

GitHub 主页不是完整简历，而是一个快速入口。读者应该在十几秒内知道：

- 你是谁。
- 你现在关注什么。
- 有哪些代表项目或文章。
- 可以去哪里继续了解你。

## 建议结构

1. 一句身份介绍。
2. 当前关注方向。
3. Notebook / Blog / Projects 链接。
4. 代表项目或文章。
5. 技术栈图标。

## 注意事项

- 不要堆太多 badge。
- 不要把所有仓库都列出来。
- 不要写已经过时的方向。
- 尽量让博客和 profile 互相链接。
