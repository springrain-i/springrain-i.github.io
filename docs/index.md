## 内容边界

- 技术笔记：先保证准确、可执行、可更新。
- 博客文章：讲清楚问题背景、方案取舍和最终结果。
- 项目展示：不仅放链接，也说明项目解决了什么问题。
- 生活内容：保留少量，但不再混在技术主导航里。
